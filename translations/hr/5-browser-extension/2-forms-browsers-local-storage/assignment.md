# Usvoji API

## Upute

API-jevi mogu biti vrlo zabavni za korištenje. Ovdje je [popis mnogih besplatnih](https://github.com/public-apis/public-apis). Odaberite jedan API i izradite ekstenziju za preglednik koja rješava neki problem. To može biti mali problem, poput nedostatka slika kućnih ljubimaca (pa isprobajte [dog CEO API](https://dog.ceo/dog-api/)) ili nešto veće - zabavite se!

## Rubrika

| Kriterij | Izvrsno                                                                  | Zadovoljavajuće                          | Potrebno poboljšanje    |
| -------- | ------------------------------------------------------------------------ | ---------------------------------------- | ----------------------- |
|          | Potpuna ekstenzija za preglednik je predana koristeći API s gornjeg popisa | Djelomična ekstenzija za preglednik je predana | Predano rješenje ima greške |
