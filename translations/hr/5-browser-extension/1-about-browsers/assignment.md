# Preoblikujte svoju ekstenziju

## Upute

Kodna baza za ovu ekstenziju dolazi s unaprijed definiranim stilovima, ali ih ne morate koristiti; učinite ekstenziju svojom tako da preoblikujete njezin CSS datoteku.

## Rubrika

| Kriterij | Primjeran                                    | Zadovoljavajući       | Potrebno poboljšanje |
| -------- | -------------------------------------------- | --------------------- | --------------------- |
|          | Kod je predan s funkcionalnim novim stilovima | Stilizacija je nepotpuna | Stilovi su neispravni |
