# Refaktoriranje CSS-a

## Upute

Preoblikujte terarij koristeći Flexbox ili CSS Grid i napravite snimke zaslona kako biste pokazali da ste ga testirali na nekoliko preglednika. Možda ćete trebati promijeniti oznake, pa stvorite novu verziju aplikacije s umjetničkim elementima na mjestu za vaš refaktor. Ne brinite o tome da elementi budu povlačivi; za sada samo refaktorirajte HTML i CSS.
