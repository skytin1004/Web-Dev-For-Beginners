# Programiranje vođeno događajima - Izradite igru tipkanja

## Uvod

Tipkanje je jedna od najpodcjenjenijih vještina programera. Sposobnost brzog prenošenja misli iz glave u uređivač omogućuje slobodan protok kreativnosti. Jedan od najboljih načina za učenje je igranje igre!

> Dakle, izradimo igru tipkanja!

Koristit ćete JavaScript, HTML i CSS vještine koje ste dosad stekli kako biste stvorili igru tipkanja. Igra će igraču prikazati nasumični citat (koristimo citate iz [Sherlocka Holmesa](https://en.wikipedia.org/wiki/Sherlock_Holmes)) i mjeriti koliko je vremena igraču potrebno da ga točno otipka. Koristit ćete JavaScript, HTML i CSS vještine koje ste dosad stekli kako biste stvorili igru tipkanja.

![demo](../../../4-typing-game/images/demo.gif)

## Preduvjeti

Ova lekcija pretpostavlja da ste upoznati sa sljedećim konceptima:

- Kreiranje tekstualnih unosa i kontrola gumba
- CSS i postavljanje stilova pomoću klasa
- Osnove JavaScripta
  - Kreiranje niza
  - Generiranje nasumičnog broja
  - Dobivanje trenutnog vremena
