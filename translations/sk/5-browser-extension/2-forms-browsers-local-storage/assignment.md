# Prijmite API

## Pokyny

API môžu byť veľmi zábavné na hranie. Tu je [zoznam mnohých bezplatných API](https://github.com/public-apis/public-apis). Vyberte si jedno API a vytvorte rozšírenie prehliadača, ktoré rieši nejaký problém. Môže to byť taký malý problém, ako je nedostatok obrázkov domácich miláčikov (napríklad vyskúšajte [dog CEO API](https://dog.ceo/dog-api/)) alebo niečo väčšie – bavte sa!
