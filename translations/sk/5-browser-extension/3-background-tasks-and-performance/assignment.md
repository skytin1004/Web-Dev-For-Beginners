# Analyzujte výkon webovej stránky

Poskytnite podrobnú správu o webovej stránke, ktorá ukazuje oblasti, kde je výkon problematický. Analyzujte, prečo je stránka pomalá a čo by ste mohli urobiť, aby ste ju zrýchlili. Nespoliehajte sa iba na nástroje prehliadača, ale vykonajte výskum o ďalších nástrojoch, ktoré môžu pomôcť vašej správe.

## Kritériá hodnotenia

| Kritérium | Vynikajúce                                                                                                 | Dostatočné                  | Vyžaduje zlepšenie            |
| --------- | ---------------------------------------------------------------------------------------------------------- | --------------------------- | ----------------------------- |
|           | Predložená správa obsahuje podrobnosti nielen z nástrojov prehliadača, ale aj z nástrojov tretích strán, ak sú dostupné | Predložená je základná správa | Predložená je minimálna správa |
